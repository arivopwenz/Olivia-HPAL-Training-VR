# Safety Glasses

`SafetyGlasses.fbx` is exported for Unity with `-Z Forward`, `Y Up`, applied
rotation and scale, and its pivot at the asset origin.

Texture setup for Unity Standard or URP Lit:

- Base Map / Albedo: `SafetyGlasses_BaseColor.png`
- Normal Map: `SafetyGlasses_Normal.png` (set Texture Type to Normal Map)
- Metallic Map: `SafetyGlasses_MetallicSmoothness.png`
- Occlusion Map: `SafetyGlasses_Occlusion.png`

The original packed channel texture is also included as
`SafetyGlasses_ORM.png`: red is ambient occlusion, green is roughness, and
blue is metallic.
